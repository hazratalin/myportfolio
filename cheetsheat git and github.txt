❌ Problem (Why this error happens)
git@github.com: Permission denied (publickey).


This means:

Your remote URL is using SSH

git@github.com:hazratalin/myportfolio.git


BUT your computer does not have an SSH key added to GitHub

So GitHub doesn’t know who you are.

✅ TWO EASY SOLUTIONS

I’ll show Option 1 (Easiest) and Option 2 (Professional SSH)

✅ OPTION 1 (EASIEST – RECOMMENDED FOR BEGINNERS)
Switch from SSH to HTTPS
1️⃣ Change remote URL to HTTPS

Run this command:

git remote set-url origin https://github.com/hazratalin/myportfolio.git


Check:

git remote -v


You should see:

https://github.com/hazratalin/myportfolio.git

2️⃣ Push again
git push -u origin main


GitHub will ask:

Username → hazratalin

Password → ❌ NOT your GitHub password
👉 Use GitHub Personal Access Token

3️⃣ Create GitHub Token (One Time)

GitHub → Settings

Developer settings

Personal access tokens

Tokens (classic)

Generate new token

Select:

✅ repo

Copy token

📌 Paste token as password

✅ DONE — your code will push successfully 🎉

✅ OPTION 2 (SSH – Advanced & Professional)

If you want to keep SSH (git@github.com), do this:

1️⃣ Generate SSH key
ssh-keygen -t ed25519 -C "your_email@gmail.com"


Press Enter for everything.

2️⃣ Start SSH agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

3️⃣ Copy SSH key
cat ~/.ssh/id_ed25519.pub


Copy the output.

4️⃣ Add key to GitHub

GitHub → Settings

SSH and GPG keys

New SSH key

Paste key

Save

5️⃣ Test connection
ssh -T git@github.com


You should see:

Hi hazratalin! You've successfully authenticated.


Now push:

git push -u origin main

✅ WHAT I RECOMMEND FOR YOU

👉 Use OPTION 1 (HTTPS) for now
👉 Later, learn SSH
